One line about office life, written to make the AI judge laugh.

## The joke

> My review said I "work well independently" — corporate for "nobody knows what you do" — so this year I'm aiming for "works well with others" and a witness.

## How it works

`main.py` (Python 3.13, stdlib only) writes the joke to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT/entry.txt`), enforcing the bounty gate itself:
UTF-8 text, 1–200 characters, a single non-blank line.
